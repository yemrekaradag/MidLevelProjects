### ⚙️ Mid Level Console Projects

This repository contains **five intermediate-level C# console applications**, each designed to practice algorithmic thinking, clean code principles, and modular structure.  
Each project is located on a **separate branch** — you can switch between them to explore individually.

---

#### 📁 Available Projects

| # | Project Name | `Branch` | Description |
|---|---------------|-----------|--------------|
| 1 | **Geometric Calculator** | `GeometryCalculatorApp` | Calculates **area**, **perimeter**, or **volume** based on the selected geometric shape (Circle, Square, Triangle, Rectangle, etc.). Applies SRP and modular design principles. |
| 2 | **Pair Sum Algorithm** | `NumberPairCalculator` | Takes *n* integer pairs as input. If both numbers are different, prints their sum; if they are equal, prints the **square of their sum**. |
| 3 | **Compare with 67 Algorithm** | `DifferenceCalculator` | Checks whether each number is smaller or greater than 67. For smaller numbers, calculates the **sum of differences**; for greater ones, calculates the **sum of squared absolute differences**. |
| 4 | **Swap First and Last Character** | `SwapFirstLastCharApp` | Takes one or more words as input and swaps the **first and last characters** of each word, then prints the new result. |
| 5 | **Consonant Checker** | `DoubleConsonantChecker` | Detects whether a given word contains **two consecutive consonants**. Prints `True` if found, otherwise `False`. |

---

#### 🔀 How to Use

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yemrekaradag/MidLevelProjects.git
   ```

2. **List all available branches:**
   ```bash
   git branch -a
   ```

3. **Switch to a specific project branch:**
   ```bash
   git checkout <branch-name>
   ```

---

#### 💡 Notes

- Each project follows **Single Responsibility Principle (SRP)** and is split into multiple classes for clarity.  
- Avoids repetitive code using clean and reusable methods.  
- Ideal for practicing **basic algorithm logic**, **user input handling**, and **console-based interactions**.
